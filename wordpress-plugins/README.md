# WordPress plugin uploads

This folder contains WordPress plugin ZIP files that are ready to upload.

Upload this file to WordPress:

```text
wordpress-plugins/stoik-seo-blog-builder.zip
```

If you do not see this file on your desktop yet, pull the branch:

```bash
git fetch origin cursor/seo-blog-builder-plugin-013c
git checkout cursor/seo-blog-builder-plugin-013c
git pull origin cursor/seo-blog-builder-plugin-013c
```

Then upload the ZIP in WordPress:

1. Go to **Plugins > Add New Plugin > Upload Plugin**.
2. Choose `stoik-seo-blog-builder.zip`.
3. Click **Install Now**.
4. Click **Activate Plugin**.
