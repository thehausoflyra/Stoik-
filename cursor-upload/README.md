# Upload this plugin from Cursor

Use this folder when you want the ready-to-upload WordPress plugin file.

Upload this ZIP to WordPress/Hostinger:

```text
cursor-upload/stoik-seo-blog-builder.zip
```

WordPress upload path:

1. Log in to WordPress.
2. Go to **Plugins > Add New Plugin > Upload Plugin**.
3. Choose `stoik-seo-blog-builder.zip`.
4. Click **Install Now**.
5. Click **Activate Plugin**.

After activation, open **SEO Blog Builder** in the WordPress admin sidebar.

Security defaults:

- The builder dashboard is admin-only.
- Publishing uses WordPress permission checks.
- Images must be valid WordPress media-library image attachments.
- The plugin does not make external API requests.
